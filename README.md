# DevWebsite

Personal developer portfolio for Chayce The Programmer. The site is intentionally
built with plain HTML and CSS so the content, accessibility, and deployment
workflow remain easy to understand and maintain.

## Local preview

Open `index.html` in a browser, or serve the repository with any static file
server. GitHub Pages deploys the contents of the default branch.

## Maintenance checklist

- Keep the homepage focused on the strongest six projects.
- Give each project page a short summary, current status, technologies, and a
  link to its source or demo when one is available.
- Use descriptive image alt text and validate links after adding pages.
- Update the copyright year and project status when the site changes.
